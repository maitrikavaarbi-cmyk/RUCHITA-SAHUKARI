## ⚙️ How to make the Live Link visible on your GitHub Repository page

To display the website link directly in the header of your GitHub repository so recruiters can click it with 1 tap:
1. Go to your **GitHub Repository** main page in your browser.
2. Look at the right-hand sidebar where it says **"About"**.
3. Click the ⚙️ **Gear icon** next to **About**.
4. In the **Website** field, paste:
   ```
   https://ais-pre-xju72axiexib5whhw42w6q-915427340298.asia-southeast1.run.app
   ```
5. In the **Description** field, paste:
   ```
   Ruchita Sahukari — Professional Journalism, The Lit Scroll & Media Communications Portfolio
   ```
6. Check the box **"Use your project's website"** and click **Save changes**. The clickable live website URL will now be shown prominently at the top right of your repository!

## 🚀 How to Host with an Independent Link (No AI Studio)

You can host this portfolio completely independently with your own personal URL:

### Option 1: Official GitHub Pages Link (`https://YOUR-USERNAME.github.io/YOUR-REPO/`)
We have already added the automated deployment file (`.github/workflows/deploy.yml`) to this repository.
To turn it on in GitHub:
1. Open your repository on **GitHub**.
2. Click on **Settings** (tab at the top).
3. In the left sidebar, click **Pages**.
4. Under **"Build and deployment"** > **Source**, select **"GitHub Actions"**.
5. That's it! GitHub will automatically build and publish your website to:
   ```
   https://YOUR-USERNAME.github.io/YOUR-REPO/
   ```
   *(This URL has zero AI Studio branding and is hosted directly on GitHub).*

---

### Option 2: 1-Click Free Hosting on Vercel (`https://ruchita-portfolio.vercel.app`)
For the fastest and cleanest custom domain:
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub (100% free).
2. Click **"Add New Project"** and select your GitHub portfolio repository.
3. Click **Deploy**.
4. In ~30 seconds you get a custom URL like:
   ```
   https://ruchita-sahukari.vercel.app
   ```
   You can also connect any custom domain (e.g. `ruchitasahukari.com`) with one click for free.

## 🌟 Key Features

1. **Two Distinct Link Modes**:
   - **Public Mode (`/`)**: Read-only, distraction-free dossier designed for employers and newsrooms.
   - **Admin Mode (`/?edit=ruchita`)**: Secret studio enabling Ruchita to update articles, upload photos, and manage content with live server synchronization.

2. **3-Pillar Foundation**:
   - **01. REPORT**: Investigative reporting, ground dispatches, and Peace to Camera (PTC) video packages.
   - **02. CREATE**: Digital storytelling, visual explainers, carousel news, and social advocacy.
   - **03. COMMUNICATE**: Corporate communications, media strategy, PR campaigns, and brand voice.

3. **Curated Portfolios & Showcases**:
   - **The Hans India & National Bylines**: Field reports, policy dispatches, and public interest investigations.
   - **The Lit Scroll**: Group E academic journalism initiative from IIMC Dhenkanal (*"No Cap, Just Facts"*).
   - **Substack In-Depth**: Long-form essays, personal columns, and cultural commentary.
   - **Ethicly Journalism Assistant**: Interactive media ethics guidelines and copy polishing tool.

4. **Interactive Recommendations & Testimonials Hub**:
   - Allows editors, peers, and mentors to leave verified endorsements directly or import LinkedIn recommendations.

5. **Integrated AI Assistant**:
   - Powered by **Google Gemini 3.7 Flash** to auto-generate excerpts, structured takeaways, and metadata tags from pasted article drafts or URLs.

## 🚀 Local Development Setup

### Prerequisites
- Node.js 20+ installed
- npm or bun

### Installation & Run

```bash
# 1. Clone repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

# 2. Install dependencies
npm install

# 3. Start development server (serves on http://localhost:3000)
npm run dev

# 4. Build for production
npm run build
npm start
```
